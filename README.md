# Controle para Biblioteca em JS

## Sobre o projeto
O projeto foi desenvolvido como método prático avaliativo, referente ao Módulo 1 - Semana 6 do curso Front-End Angular, oferecido pelo SCTec.
O sistema visa facilitar o gerenciamento de um acervo de livros de uma biblioteca. Permite que o usuário execute através do terminal, faça o cadastro de novos livros, controle empréstimos e devoluções, e ainda tenha acesso a estatísticas da biblioteca.

## Objetivo
Praticar conceitos estudados no Módulo 01, entre eles:

- Variáveis (let, const)
- Estruturas condicionais (if, else, ternário, switch)
- Estruturas de repetição (for, while, do while)
- Versionamento e desenvolvimento colaborativo com GitHub
- Arrays e objetos
- Funções e métodos
- Classes e construtores
- Encapsulamento
- Módulos
- Entrada de dados com prompt-sync

## Funcionalidades
- Listar livros cadastrados
- Buscar livro pelo título
- Listar apenas livros disponíveis
- Cadastrar novos livros
- Realizar empréstimos
- Realizar devoluções
- Exibir estatísticas da biblioteca
  
## Como executar
- Clone o repositório
- Utilizando o terminal, instale a dependência necessária (npm install)
- Utilizando o node.js no terminal, execute: node index.js
